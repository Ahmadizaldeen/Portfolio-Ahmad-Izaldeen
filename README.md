# Portfolio Ahmad Izaldeen

A personal portfolio website built with React. It presents profile information, skills, selected projects, and a contact form—styled for a dark theme with smooth scrolling navigation and a responsive layout.

## Tech Stack

- **React** (Create React App)
- **Tailwind CSS**
- **react-icons**
- **Formspree** (contact form submissions)

## Features

- **Parallax Hero** — layered imagery with scroll-driven motion on larger viewports
- **Multilingual About** — switch between German, Arabic, and English copy
- **Skills Animation** — progress bars animate into view when the section is visible
- **Contact Form** — powered by Formspree
- **Mobile Responsive** — layout and navigation adapted for small screens

## Getting Started

```bash
npm install
npm start
```

Runs the app in development mode. Open [http://localhost:3000](http://localhost:3000) in your browser.
